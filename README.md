# STM32-HID-Joystick

Custom HID joystick based around STM32G431RB Nucleo Board with Arduino HAT. Programmed using STM32 CUBE IDE. This is the mapping tested sucessfully using Windows USB Joystick configuration and mapped in-game as required. 

* 4x ADC (Roll, Pitch, Throttle, Yaw)
* Buttons
    * Top Control Hatch Button =  Button 4
    * Trigger = Button 2
    * Side Button = Button 3
    * Paddle Button = Button 5
    * Encoder Button = Button 1
